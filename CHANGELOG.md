# Changelog

## 1.9 — build 12

First public release.

- Interactive radial disk usage map.
- Folder, system disk, user home, and external drive analysis.
- Standard and deep scanning with live progress.
- Quick Look previews, keyboard navigation, and Finder actions.
- Protected cleanup flow with safeguards for critical system folders.
- Formatting of physical external drives.
- Interface available in 13 languages.
- Universal build for Apple Silicon and Intel Macs.

### Known limitation

The current build uses a local code-signing certificate and is not notarized by Apple. On first launch, macOS may require the user to allow the app in **System Settings → Privacy & Security**.
