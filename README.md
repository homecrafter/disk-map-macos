**Disk Map** is a free native macOS utility that shows what is taking up space on your Mac.

Developer: **Andrey Minenkov**

Current version: **1.9 (build 12)**

## Features

- Scan a folder, disk, user home, or external drive.
- Explore storage with an interactive radial map and a list of the largest items.
- Navigate folders and preview files with Quick Look by pressing `Space`.
- Reveal items in Finder or move them to Trash.
- Collect multiple items for cleanup and securely delete selected files after confirmation.
- See free, hidden, and purgeable space.
- Use standard or deep scanning with live progress.
- Format physical external drives as exFAT, APFS, or FAT32 with safety checks.
- Switch between 13 interface languages from inside the app.
- Work without registration, ads, analytics, or network connections.

All analysis runs locally on your Mac. File information is never sent anywhere.

## Installation

1. Open the downloaded DMG.
2. Drag **Карта диска** to the **Applications** folder.
3. Launch the app from **Applications**.

The app is not yet notarized by Apple. If macOS blocks the first launch:

1. Open **System Settings → Privacy & Security**.
2. Scroll down and click **Open Anyway** next to the Disk Map message.
3. Confirm the launch.

This is normally required only for the first launch of a new installation. See [Apple’s instructions for safely opening apps on Mac](https://support.apple.com/102445).

Full Disk Access is optional and is only needed for deep analysis of protected folders.
