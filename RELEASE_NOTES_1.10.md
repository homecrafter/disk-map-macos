# Disk Map 1.10

This update removes the unnecessary rescan after changing the interface language.

## Changes

- The language changes immediately without restarting Disk Map.
- The completed scan and radial map remain open.
- The current folder, selected item, and back/forward history are preserved.
- File-size formatting updates for the selected language.
