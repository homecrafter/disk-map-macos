# Security Policy

Disk Map can delete files and format external drives, so security problems are taken seriously.

## Supported version

Only the latest release on the [Releases](https://github.com/homecrafter/disk-map-macos/releases) page receives fixes.

## Reporting a vulnerability

Please do not describe security problems in public issues or discussions.

Report them privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**.

Please include the Disk Map version, your macOS version and the steps to reproduce the problem. Do not attach private files or personal data.
